## New Features

### API Gateway / Model Browser

Full provider-based model selection system accessible from Settings → Agent:

- **9 built-in providers:** Ollama (Local), Ollama Cloud, OpenAI, Anthropic, Groq, OpenRouter, Google Gemini, Nous Portal, Custom
- Provider registry (`providers.json`) with per-provider config: base URL, auth type, model endpoints, model filtering
- Per-provider model fetchers with parsing for Ollama, OpenAI-compatible, and Gemini APIs
- Connection validator — test connection and validate model availability per provider
- Endpoint builder — constructs provider-specific chat URLs (Ollama native, OpenAI-compat, Gemini model-in-path)
- AgentSettings redesigned with provider dropdown, model dropdown, test connection button, refresh models button, manual config mode toggle
- Nous Portal: hardcoded models (Hermes 4.3 36B, Hermes 4 70B, Hermes 4 405B) with 128k context
- Anthropic: hardcoded models (Claude Opus 4, Sonnet 4, 3.5 Haiku)

### Auto-Update Service

- Full download-and-install pipeline from GitHub Releases
- Checks `releases/latest` API, skips drafts and prereleases
- Platform-aware asset matching (`dist-windows.zip`, `dist-macos.zip`, `dist-linux.zip`)
- Streaming download with progress tracking (bytes/percent via IPC)
- Automatic extraction (PowerShell `Expand-Archive` on Windows, `unzip` on macOS/Linux)
- Staged swap: writes a platform-specific swap script, launches it detached, then exits and relaunches
- Auto-checks on startup (10s delay) and every hour thereafter

### Other Additions

- DOMPurify for HTML sanitization (XSS prevention)
- Shared `auth-headers.ts` module (extracted from 3 duplicate implementations)
- `setChatMessages()` batch store action (fixes O(n²) re-renders in chat panel)
- aria-labels on all icon-only buttons in Toolbar and FloatingToolbar
- `knip` script in package.json for dead code detection
- Current version display in editor footer
- Tab bar context menu (Close, Close Others, Close to Right, Close All, Reveal in Explorer)
- Reduced motion support (`motion: { reducedMotion: 'system' }` in ThemeProvider)

## Security

- **API key removed from renderer localStorage** — No longer stored in plaintext. Key stored only in main process (encrypted via `safeStorage`). Renderer fetches transiently via `agent.getConfig()`
- **API key logging removed** — Agent-bridge was logging first 20 chars of API key to console. Now logs only key length
- **XSS prevention** — `dangerouslySetInnerHTML` in split-view preview now sanitized with DOMPurify
- **SSRF protection** — Agent `web_fetch` tool blocks private IP ranges (10.x, 172.16-31.x, 192.168.x, 127.x, 169.254.x), metadata endpoints, and non-http protocols
- **URL filtering** — `shell.openExternal` filtered to http(s) only — blocks `javascript:`, `file:`, `data:` URLs

## Performance

- **12% bundle reduction** — 18 conditionally-rendered panels lazy-loaded via `React.lazy()` + `Suspense` (3.5MB → 3.08MB). Panels split into separate chunks: VcsPanel (114KB), SettingsPanel (77KB), CommandPalette (64KB), AgentWorkspacePanel (55KB), etc.
- **`requestAnimationFrame` throttling** on editor `onUpdate` — batches 30-50+ key-repeat events/sec into one per frame. Eliminates lag when holding down a key
- **`getHTML()` caching** — skips expensive serialization when doc signature (size + child count) hasn't changed
- **Selective Zustand subscriptions** — EditorPanel, AgentWorkspacePanel, SuggestionsManager, EnhancedEditorPanel all use individual `useAppStore(s => s.field)` selectors instead of full-store destructure
- **Grammar/context analysis gating** — debounced from 500ms/800ms to 2000ms/2500ms to avoid CPU during fast typing
- **FloatingToolbar** position updates throttled via rAF
- **Toolbar** editor attribute reads memoized via `useMemo`
- **App.tsx** reactive selectors — 24 `getState()` calls in render replaced with proper `useAppStore(s => s.field)` selectors
- **Inline suggestion clear** guarded by visibility check — avoids 2 unnecessary store mutations per keystroke
- **`setDirty()` deferred** to content sync timer — no more store mutation on first keystroke

## Fixed

- **Model fetch re-render loop** — `useEffect` with `selectedProviderId` dependency caused rapid repeated fetch calls, producing visible window flashing. Replaced with explicit fetch-on-dropdown-change using a ref guard
- **New tab save bug** — Creating a new tab and saving would write to the previous tab's file path. `addDocTab` now resets `currentFilePath` to `null`
- **CollabPanel positioning** — Was rendering in document flow, creating a "shadow tab". Now renders as fixed overlay with backdrop
- **AutoUpdateService timer leak** — Hourly check timer never destroyed. `destroy()` now called on `window-all-closed`
- **`handleRetryMessage`** — Was just copying old message to input. Now removes failed assistant message and re-sends
- **`handleDeleteMessage` O(n²)** — Was calling `clearChat()` + `forEach(addChatMessage)`. Now uses batch `setChatMessages()`
- **AgentWorkspacePanel empty-state chips** — "Summarize" and "Generate outline" were no-ops. Now wired to real handler functions
- **10+ stub IPC handlers** — Returned `{ success: true }` without doing anything. Removed
- **Stale `listPresets` type** — Removed from `window.d.ts` (never existed in preload)
- **Recent Files submenu** — Never closed when mouse moved away from trigger item
- **Duplicate auth header builder** — Consolidated to shared `auth-headers.ts`
- **CollabPanel server guard** — Toolbar button now checks for configured port before opening
